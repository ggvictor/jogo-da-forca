# 🎯 Projeto: Jogo da Forca

Este projeto é um **Jogo da Forca** desenvolvido com **HTML**, **CSS** e **JavaScript**, onde o jogador pode escolher entre **4 categorias** diferentes de palavras.  
O objetivo é adivinhar a palavra antes que o boneco seja totalmente "enforcado".
